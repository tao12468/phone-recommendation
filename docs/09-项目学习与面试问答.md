## 二、面试常见问题与答案

### 1. 请介绍一下你的手机推荐项目

答案要点：

```text
这是一个前后端分离的个性化手机推荐系统。
后端用 Flask 提供 RESTful API，前端用 HTML/CSS/JS 实现页面。
数据来自爬虫，清洗后存入 MySQL，再经过特征工程和三种推荐算法生成结果。
用户行为会回传，动态更新偏好。
```

示例回答：

> 我做了一个个性化手机推荐平台。用户注册登录后填写预算、品牌、场景，系统会混合推荐手机，并支持收藏和机型对比。后端用 Flask，前端用原生 HTML/CSS/JS，数据存 MySQL。我做了爬虫采集手机数据，清洗和特征工程后，实现了内容过滤、协同过滤和混合推荐。用户浏览和收藏后，系统会更新他的偏好，让推荐越来越准。

### 2. 前后端是怎么通信的

答案：

```text
前端通过 fetch 请求后端 RESTful API，后端返回 JSON。
前端拿到 JSON 后用 JavaScript 渲染页面。
```

### 3. JWT 登录是怎么工作的

答案：

```text
用户登录成功后，后端生成一个 JWT 令牌返回前端。
前端把令牌存在 localStorage。
以后每次请求都在请求头带上 Authorization: Bearer 令牌。
后端解析令牌，识别用户身份。
```

### 4. 为什么用 MySQL，而不是把数据放文件里

答案：

```text
MySQL 支持持久化、结构化查询、去重和事务。
文件适合少量数据，数据多了查询和管理困难。
数据库还能通过索引提升查询速度。
```

### 5. 内容过滤和协同过滤有什么区别

答案：

```text
内容过滤：根据物品本身的特征和用户偏好匹配，不需要其他用户数据，适合冷启动。
协同过滤：根据其他相似用户的行为推荐，能发现用户没表达过的新物品，但需要交互数据。
```

### 6. 冷启动怎么处理

答案：

```text
新用户没有交互数据时，先使用内容过滤或热门推荐。
等用户行为积累后，再引入协同过滤。
```

### 7. 缺失值怎么处理

答案：

```text
能解析的从名称和描述里补；不能解析的用同品牌中位数，再用全量中位数。
不随意编造数据。
```

### 8. 爬虫怎么防止被封

答案：

```text
控制请求频率、设置 User-Agent、失败重试、分页抓取。
```

### 9. 你的项目有什么难点，怎么解决的

答案：

```text
难点之一是数据缺失。我通过解析原始描述、同品牌中位数填充来解决。
难点之二是推荐冷启动。我用内容过滤和热门推荐兜底。
```

### 10. 旅行规划 Agent 的 ReAct 是什么

答案：

```text
ReAct 是 Reasoning + Acting。
Agent 不断循环：思考、调用工具、观察结果，直到完成回答。
```

### 11. Agent 怎么调用外部工具

答案：

```text
把高德地图、天气、搜索等 API 封装成统一格式的工具。
Agent 根据思考结果，选择要调用的工具，传入参数，拿到结果。
```

### 12. RAG 记忆是干什么的

答案：

```text
把历史旅行方案保存到 ChromaDB。
新问题时检索相关记忆，拼接进提示词，让回答更连贯。
```

### 13. FastAPI 提供了哪些接口

答案：

```text
GET /health 健康检查
POST /chat  旅行规划对话
```

### 14. 如果重新做，你会改进什么

答案：

```text
后端迁移到 Spring Boot，前端迁移到 Vue。
加入 Redis 缓存。
增加推荐效果指标和 A/B 测试。
```
