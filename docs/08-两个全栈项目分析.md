# 两个全栈项目分析文档

这份文档分析简历里的两个项目：手机推荐平台和智能旅行规划 Agent。

## 一、项目一：数据驱动的个性化手机推荐平台

### 1. 项目定位

这是一个前后端分离的 Web 系统。用户注册登录后，可以浏览手机、填写偏好、获得推荐、收藏和对比手机。

### 2. 技术栈

```text
后端：Python + Flask
前端：HTML + CSS + JavaScript
数据库：MySQL
数据处理：Pandas、NumPy、scikit-learn
爬虫：Requests + BeautifulSoup
版本管理：Git + GitHub
```

### 3. 系统架构

```text
浏览器前端
   |
   | HTTP + JSON
   v
Flask 后端
   |
   | SQL
   v
MySQL
```

前端只负责展示，后端负责业务逻辑，数据库负责持久化。

### 4. 核心模块

```text
用户模块      注册、登录、JWT 鉴权
数据模块      爬虫采集、清洗、特征工程
推荐模块      内容过滤、协同过滤、混合推荐
反馈模块      记录行为、更新偏好
前端模块      首页、推荐、收藏、详情、对比
```

### 5. 数据流

```text
爬虫采集手机数据
   -> 清洗与缺失值填充
   -> 写入 MySQL
   -> 特征工程
   -> 推荐算法
   -> 用户行为反馈
   -> 更新用户偏好
```

### 6. 数据库设计

```text
users               用户表
phones_clean        手机清洗数据表
phones_features     手机特征表
user_interactions   用户交互表
user_preferences    用户偏好表
```

### 7. 推荐算法

内容过滤：

```text
用户偏好和手机特征匹配打分
```

协同过滤：

```text
找到相似用户，推荐他们喜欢的手机
```

混合推荐：

```text
内容过滤 55% + 协同过滤 45%
```

### 8. 项目亮点

- 完整的数据闭环
- 三种推荐算法
- 行为反馈动态更新偏好
- 前后端分离
- 自动化测试

## 二、项目二：智能旅行规划 Agent

### 1. 项目定位

用户用自然语言描述旅行需求，Agent 自动推理、调用工具、汇总结果，生成包含天气、景点、行程和预算的旅行方案。

### 2. 技术栈

```text
后端：Python + FastAPI
大模型：DeepSeek API
推理模式：ReAct
记忆：ChromaDB + RAG
前端：demo.html
```

### 3. 核心流程

```text
用户输入需求
   -> Agent 思考
   -> 调用工具（天气、景点、地图、预算）
   -> 观察结果
   -> 继续思考
   -> 输出旅行方案
```

### 4. 核心模块

```text
agent.py      ReAct 推理循环
tools.py      旅行工具集合
memory.py     长期记忆与 RAG
config.py     环境变量
main.py       命令行入口
api/main.py   FastAPI 接口
```

### 5. 工具设计

```text
高德地图   地理编码、路线
OpenWeather 天气查询
SerpAPI     景点搜索
```

工具统一输入输出格式，方便 Agent 调用。

### 6. 项目亮点

- 手写 ReAct 循环
- 工具解耦与 Tool Registry
- ChromaDB RAG 长期记忆
- 错误降级与成本控制

## 三、两个项目的关系

```text
手机推荐平台：传统 Web 全栈 + 数据库 + 推荐算法
旅行规划 Agent：AI 应用 + 工具调用 + 记忆
```

两者共同展示后端、前端、数据库、算法、AI 应用和工程能力。
