# 从零学习完成手机推荐项目

这份文档的目标：即使你写代码还不熟练，也能照着它理解这个项目是怎么从零做出来的，并能自己启动、修改和完成。

## 1. 这个项目做了什么

一个 Web 系统，主要功能是：

- 用户注册、登录
- 首页展示所有手机，滚动加载下一批
- 用户填写预算、品牌、场景、系统偏好
- 系统推荐手机
- 用户收藏手机
- 查看手机详情
- 选择 2 到 3 款手机进行对比
- 系统记录用户行为，动态更新用户偏好

推荐使用了三种算法：

```text
基于内容过滤
基于用户的协同过滤
混合推荐
```

## 5. 后端是怎么工作的

### 5.1 Flask 是什么

Flask 负责接收浏览器请求，返回 JSON 数据。

一个最简单的接口：

```python
@app.get("/api/health")
def health():
    return jsonify({"status": "ok"})
```

解释：

```text
@app.get：当有人访问这个地址时
health：执行这个函数
jsonify：把结果转成 JSON 返回
```

### 5.2 前端请求后端

前端 JavaScript 这样请求：

```javascript
const response = await fetch("/api/phones/all?page=1&page_size=20");
const data = await response.json();
```

意思就是：

```text
请求地址
拿到响应
把响应转换成 JSON
```

## 6. 数据库是怎么工作的

数据库用来保存数据，不会被程序重启后丢失。

项目里的表：

```text
users                用户
phones_clean         清洗后的手机
phones_features      手机特征
user_interactions    用户交互记录
user_preferences     用户偏好
```

Python 写入 MySQL 的核心：

```python
connection = pymysql.connect(host="127.0.0.1", user="root", password="你的MySQL密码", database="phone_recommender")

sql = "INSERT INTO users (username, password_hash) VALUES (%s, %s)"
cursor.execute(sql, ("张三", "加密后的密码"))
connection.commit()
```

`%s` 是占位符，会被真实数据替换。

## 8. 数据是怎么清洗的

原始数据不能直接用，需要清洗。

清洗内容：

```text
手机名称只保留型号
价格、屏幕、电池、内存范围检查
CPU 文本清理
使用场景拆分
去重
缺失值填充
```

核心代码：

```python
frame = pd.DataFrame(records)
frame["name"] = frame["name"].apply(extract_product_name)
frame = frame.drop_duplicates(subset=["source_id"])
```

缺失值填充：

```python
frame["battery"] = frame["battery"].fillna(
    frame.groupby("brand")["battery"].median()
)
```

## 10. 三种推荐算法

### 10.1 内容过滤

根据用户偏好和手机特征打分：

```python
score = (
    budget_match * 0.30
    + brand_match * 0.15
    + scene_match * 0.25
    + os_match * 0.10
    + performance * 0.20
)
```

### 10.2 协同过滤

找到相似用户，推荐他们喜欢的手机。

```python
similarity = cosine_similarity(user_item_matrix)
```

### 10.3 混合推荐

把两种算法分数融合：

```python
score = content_score * 0.55 + collaborative_score * 0.45
```

## 11. 行为反馈怎么做

用户浏览、点击、收藏后：

```text
记录行为
更新用户预算
更新品牌、场景、系统偏好
```

核心：

```python
preferences["budget"] = (
    preferences["budget"] * (1 - alpha)
    + phone["price"] * alpha
)
preferences["brand_counts"][brand] += 1
```

## 12. 用户登录怎么做

密码用 BCrypt 加密，登录后发 JWT 令牌。

```text
注册：保存用户名 + 加密密码
登录：验证密码 -> 发令牌
后续请求：带令牌 -> 后端识别用户
```
