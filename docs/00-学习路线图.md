# 从零实现学习路线图

## 阶段 0：项目初始化与环境确认

目标：把开题报告变成可以逐项执行的开发任务，确认电脑环境，并建立干净的工程目录。

完成标准：

- 项目目录、说明文档、需求拆解文档建立完成
- 开发环境已检查并记录
- 明确每一阶段要交付的内容

## 阶段 1：最小可运行闭环

目标：先跑通“打开页面 → 看到手机列表 → 得到简单推荐”的最短流程。

细分任务：

- 建立 Flask 后端入口
- 内置 10 款左右手机样本
- 提供健康检查接口
- 提供手机列表接口
- 提供最简单的推荐接口
- 建立基础前端页面并调用接口

## 阶段 2：数据库与数据层

目标：让数据不再写死在代码里，而是可以持久化保存。

细分任务：

- 设计用户、手机、收藏、行为日志、推荐日志等表
- 先用 SQLite 建表
- 编写手机数据导入脚本
- 预留 MySQL 迁移脚本
- 完成手机数据的新增、查询、筛选、详情接口

## 阶段 3：用户与偏好采集

目标：实现注册登录和首次偏好问卷。

细分任务：

- 用户注册与登录
- 密码加密存储
- JWT 登录令牌
- 偏好问卷设计
- 将偏好保存为用户特征向量

## 阶段 4：数据采集与特征工程

目标：获得可用的手机规格数据，并加工成推荐算法能用的特征。

细分任务：

- 编写手机信息爬虫脚本
- 数据去重、异常值处理、缺失值填充
- 构建数值特征和类别特征
- 计算性价比特征
- 划分机型定位
- 生成竞品关联特征

## 阶段 5：混合推荐算法

目标：实现报告中的三类推荐，并融合成最终结果。

细分任务：

- 基于内容过滤：特征向量与余弦相似度
- 基于用户协同过滤：用户-手机交互矩阵
- 知识图谱关系推荐：同品牌、同价位段、同定位等
- 热门推荐冷启动策略
- 加权混合与切换式混合

## 阶段 6：行为反馈闭环

目标：让系统根据用户行为不断调整推荐结果。

细分任务：

- 记录浏览、点击、收藏、对比行为
- 将隐式反馈转换为偏好变化
- 动态更新用户特征向量
- 动态调整推荐权重
- 形成“采集-推荐-反馈-优化”闭环

## 阶段 7：Web 前端完善

目标：完成报告要求的全部页面功能。

细分任务：

- 注册登录页
- 偏好问卷页
- 推荐列表页
- 手机详情页
- 收藏夹页
- 机型横向对比页
- 用户画像与数据可视化

## 阶段 8：系统集成、部署与测试

目标：让系统稳定可用，并具备演示条件。

细分任务：

- 前后端联调
- 接口冒烟测试
- 功能测试用例
- 性能测试
- 用户满意度调查
- 本地部署与启动说明

## 阶段 9：正式技术栈迁移

目标：按开题报告补齐 Spring Boot、Vue、MySQL、Redis、Neo4j 等技术方案。

细分任务：

- 将 Flask 数据层迁移到 Spring Boot
- 将 SQLite 迁移到 MySQL
- 将关系模拟知识图谱迁移到 Neo4j
- 使用 Redis 缓存热点数据
- 使用 Vue 组件化开发前端

## 阶段 10：毕业论文撰写与答辩准备

目标：整理系统实现过程，完成论文和答辩材料。

细分任务：

- 确定论文大纲
- 绘制系统架构图、流程图、数据库图
- 整理实验数据和指标
- 撰写系统设计与实现章节
- 准备答辩演示
